# 拓荒时代｜建立自我

## 从“我能活下来”到“我们能够建立据点”

这七张按职业发散，但职业不是牌义的替代，也不是参与者必须扮演的身份。七个核心需求是：制造交付、资源认知、食物滋养、公共秩序、共享知识、合作归属、运输行动。到战车为止，开拓者拥有了向外行动的能力，却还没有解决复杂社会内部的矛盾。
