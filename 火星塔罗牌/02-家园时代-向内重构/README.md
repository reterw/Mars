# 家园时代｜向内重构

## 从“据点能运转”到“人能够好好共同生活”

假设城市通过设施和组织降低了日常外部风险，但没有消除低压、辐射、尘暴和供给约束。七个内部课题是：身体照护、心理与私人空间、气候冲击的社会分担、资源公平、城市交通可达性、旧制度退出、文化与时间整合。天气不是突然变成内部问题，而是经由基础设施与分配制度转化为内部矛盾。
