# 22张大阿卡纳｜传统与火星含义对照

> 对照当前火星版牌面与传统韦特体系的常见核心释义。采用Ⅷ力量、Ⅺ正义的编号。传统塔罗有多种解释，本表不是唯一标准，也不将占卜当作科学事实。火星城市、制度及远征均为未来叙事假设，具体科学边界见各牌背面。

| **Ⅰ 魔术师** | 意志、创造力、运用工具，将潜能化为现实 | **火星资源的转化**：把当地资源转变为氧气、材料和可交付、可维护的生产能力 |
| **Ⅱ 女祭司** | 直觉、潜意识、隐藏的知识、等待与内在智慧 | **星球信息与开发边界**：调查资源与环境，辨认未知，决定哪里能开发、哪里需等待或保护 |
| **Ⅲ 女皇** | 丰饶、自然、滋养、感官与创造力，不限于母亲或生育 | **营养与健康**：组织食物生产与供给、营养保障、医疗康复、心理支持与长期照护，使文明既能养活人口，也能照顾人的长期健康 |

| **Ⅶ 战车** | 意志、行动、方向、驾驭冲突力量与推进目标 | **运输网络与拓荒疆域**：决定扩展方向，建设交通走廊，协调运力、维护与救援 |

## 第二时代：家园

| 牌名 | 传统塔罗的核心含义 | 当前火星版主题与含义 |
| --- | --- | --- |
| **Ⅷ 力量** | 勇气、耐心、温柔的力量，调和本能而非蛮力压制 | **身体与生活**：人们开始在低重力、人工环境中度过漫长人生。工作、休息、饮食、运动与照护逐渐构成火星的日常；这里既有身体的限制，也有新的生活习惯与乐趣。 |
| **Ⅸ 隐士** | 独处、内省、寻找真理与内在指引 | **个体的方向**：当火星社会有了共同的发展方向，生活在其中的每个人，又想走向哪里？有人投入研究、信仰或创作，有人珍惜平静的日常，也有人暂时离开外界的声音，重新辨认自己的愿望。 |
| **Ⅹ 命运之轮** | 周期、转折、无常，无法完全控制的变化 | **周期与无常**：尘季、补给节奏、设备维护与意外变化伴随着城市生活。人们开始形成等待的习惯、季节性的活动，以及面对计划改变的不同态度。 |
| **Ⅺ 正义** | 公平、因果、责任、证据与判断 | **人与社会**：空气、水、住房与公共服务依赖共同建设和维护的设施。随着城市长大，人们对贡献、权利、财富、责任与归属产生了不同理解。 |
| **Ⅻ 倒吊人** | 暂停、放下控制、换位观看、自愿牺牲 | **发展的意义**：火星逐渐安稳，最初为了生存而忙碌的人们，终于有机会停下来。建设仍在继续，但人们对成功、进步和理想生活，开始有了不同的理解。 |
| **ⅩⅢ 死神** | 结束、告别与转型，旧阶段消亡后产生新可能；不直接等同肉体死亡 | **时代的转型**：火星来到发展的分水岭。一些曾经重要的事业、组织和生活方式，开始不再适合新的处境；新的方向正在出现，旧时代却不会自动退场。 |
| **ⅩⅣ 节制** | 调和、适度、整合、耐心与动态平衡 | **文化与共处**：不同背景、职业与代际的人共同定居，与地球保持联系，也逐渐长出火星自己的文化。语言、作息、节日、艺术和相处方式，在日复一日的生活中交汇。 |

## 第三时代：终局与远航

| 牌名 | 传统塔罗的核心含义 | 当前火星版主题与含义 |
| --- | --- | --- |
| **ⅩⅤ 恶魔** | 束缚、欲望、执念、依赖，以及未被看见的枷锁 | **繁荣的枷锁**：繁荣让人得到许多，也可能让人越来越难选择另一种生活。 |
| **ⅩⅥ 塔** | 突发震荡、虚假结构崩塌、被迫面对真相 | **重大挫折与发展的倒退**：重大挫折打破原有基础，发展可能收缩或倒退，但不等于文明必须毁灭。 |
| **ⅩⅦ 星星** | 希望、疗愈、信任、更新与长远指引 | **挫折之后重新开始**：尽管遭受挫折，人们仍愿意重新开始，不必恢复成过去的样子。 |
| **ⅩⅧ 月亮** | 迷雾、潜意识、恐惧、幻象与难以确认的处境 | **地火裂隙与深空迷雾**：面对信息不全、文化投射与深空未知，人们带着恐惧、猜疑和想象面对未来。 |
| **ⅩⅨ 太阳** | 喜悦、明晰、生命力、成功与坦诚 | **猩红世界的沃土**：火星不再只是任务与生存场所，而成为能够滋养人生、让人愿意生活的地方；“沃土”不是露天宜居的承诺。 |
| **ⅩⅩ 审判** | 觉醒、召唤、复盘、承担过去与重生 | **行星文明的重新交融**：经历分离与挑战后重新认识彼此，在差异中形成新的联结与共同身份，不预设统一或大团圆 |
| **ⅩⅪ 世界** | 完成、整合、圆满，一轮旅程结束并开启新循环 | **从火星走向木卫四**：整合文明能力走向远方，同时继续保障原有家园，面对新的未知 |

## 怎样理解这次改编

本项目以“愚者之旅”作为成长框架，将个人层面的课题放大到文明层面：**建立能力与秩序 → 审视代价与改革结构 → 面对深层挑战并决定怎样延续**。传统塔罗本身并不只限于个人成长，也可用于其他象征性叙事。

这不是把原牌直接翻译成职业。女祭司对应科学调查，是借用“隐藏知识与未知”的原型，不表示科学依靠直觉取代证据；女皇对应营养与健康，是借用滋养、生长与照护，不只代表农业；力量以身体与生活为入口，也要保留“柔韧而非强压”的核心。

身份可以重复且职责有别；家园牌是开放生活主题，远航牌是终局课题；不同身份都能进入，不会迫使玩家更换职业。家园不要求专业解题或形成共识。愚者、世界用于共同开场与尾声，不进入个人抽题池。
