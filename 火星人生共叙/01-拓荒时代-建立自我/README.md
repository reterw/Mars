# 拓荒时代｜建立自我

## 从“我能活下来”到“我们能够建立据点”

这七张按职业发散，但职业不是牌义的替代，也不是参与者必须扮演的身份。七个核心需求是：制造交付、资源认知、营养与健康、公共秩序、共享知识、合作归属、运输行动。到战车为止，开拓者拥有了向外行动的能力，却还没有解决复杂社会内部的矛盾。

| 编号 | 牌名与火星副题 | 职业／问题 |

可按顺序连读，也可单张开启讨论。科学背景读背面，卡面只呈现处境；正逆位不是好坏评分。

## 三张地球身份牌

拓荒时代另加入三张原创身份牌，与七类火星身份共同组成十类可选身份，不改变大阿卡纳Ⅰ—Ⅶ的编号。

| 编号 | 牌名 | 地球侧事业 |
| --- | --- | --- |
| E01 | [秩序](E01-秩序.md) | 政治支持、公共合作与权责安排 |
| E02 | [丰壤](E02-丰壤.md) | 产业、投资与经济供给 |
| E03 | [思潮](E03-思潮.md) | 社会诉求、公众交流与文化联系 |

身份自选、允许重复但须区分职责。第一时代使用身份对应牌建立事业；后两幕身份延续，另外抽时代课题。地球身份不是公共环境，也不代表整个地球具有统一意志。
