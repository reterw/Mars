## 一条连续的火星漫游之旅

**0 愚者：初抵火星 → Ⅰ—Ⅶ：建立据点 → Ⅷ—ⅩⅣ：重构家园 → ⅩⅤ—ⅩⅪ：直面终局，决定走向远方 → 新的0。**

探险家最初以为，拥有工具、找到资源、种出食物、建立规则、传播知识、学会合作并驾驭运输，就能掌控未来。城市建成后，身体的限度、心理空间、风险分担、不平等、出行障碍、制度惯性与文化差异迫使共同体重新认识自己。最终，人们必须辨认繁荣的枷锁、承受虚假结构崩塌的可能，学习重建与互信，在面对历史后决定是否远行。世界牌以木卫四登陆结束这一轮旅程；新的未知使抵达者再次成为愚者。

## 推荐玩法｜十个文明领域，贯穿三个时代

**每人负责一个领域，决定它怎样发展；每幕重新抽一张时代牌，把事业推进到下个时代。** 搞政策的制定每个时代的政策，搞食物的决定火星食物生产体系。不是轮流讲个人生活片段，也不是十个人分属三幕各讲一次。

10名玩家可分别负责政策、食物、能源、工业、交通、科学、健康、经济分配、传媒教育、居住生态。领域固定，时代牌有放回抽取、允许重复；愚者共同开场，世界共同尾声。首轮不用随机正逆位，无数值评分，约100分钟。

角色可跨时代换成继任者，主角是持续发展的事业。讲明发展路线、代价与跨域依赖，后幕继承或改革前幕选择。22张牌的副题、卡面短文、矛盾、正逆位与画面已统一重写为文明尺度；领域决策入口用于连接本幕玩法。

## 三组之间的关系

- **拓荒不是职业等级。** 七个职业是叙事入口，科学家、企业家、教育者、政府与社区组织并不构成谁高谁低；每张也可有不同职业的人承担同一课题。
- **家园不是环境已被征服。** 假设有稳定定居点，外界风险被生命保障和基础设施部分缓冲；健康、分配、作息、通勤与制度问题变得更突出。力量和隐士分开处理生理照护与心理／空间；命运之轮处理周期风险，正义处理结构性分配，避免七张都成为同一种危机。
- **终局不是线性强制结局。** 按序读是“看见阴影—击穿假象—重获希望—穿过迷雾—获得明晰—复盘召唤—完成整合”。创作时可从恶魔／塔走向失败、收缩或结束，也可经星星重建；不要求同一批居民必经毁灭。月亮与太阳分别聚焦地火理解和共享成果，不等于火星必然脱离地球。
- **世界是本版的目标性尾声。** 若选择完成全程故事，以经验证的木卫四载人登陆收束；若选择开放结局，可在审判停下、修订或拒绝本次远征。到达不证明每项过去的选择都正确，暂停远征也不等于社会失败。

## 每张牌怎样使用

1. 卡名与卡面短文可用于朗读；背面的知识背景与未来设定用于澄清条件。
2. 用开放邀请开始谈话；不要求角色扮演、解决问题、赞成定居或支持远征。
3. 正逆位是象征解读，不是概率、诊断、道德评分或宿命预言。逆位可以是阻滞、过度、否认或转向，不能一律理解成坏事。
4. 本版不是原有“时代×地点×情境”的新增分支，不改动或替换那套牌。可独立连读，也可单张抽取；不新增胜负、资源结算或占卜规则。

## 画面统一方向

保留传统大阿卡纳的识别骨架：愚者的边缘、魔术师的工具、女祭司的帷幕、正义的天平、塔的崩塌、星星的水流、世界的花环。火星元素替换场景和器物，而不是只给传统牌加一层红色滤镜。

- 拓荒：铁锈红、设备白、少量生长绿；工具与未完成结构。
- 家园：舱内暖色、公共设施蓝绿；有维修痕迹、私生活和多种人群的城市。
- 终局：深空靛蓝、应急琥珀、恢复的星光；逐渐出现地球—火星—木卫四的关系。
- 卡面主标题保留“编号＋原牌名”，火星副题次级呈现；人物不固定性别、国籍或英雄身份。
- 人在室外需穿合适的宇航服；裸身、流水、植物等传统符号放在加压空间或明确的象征边框内。航迹和系统图若为示意，不伪装为工程图。

## 体系与证据边界

三时代是本次创作结构，不是预测，也不重写既有剧本的四幕。城市、未来职业、公共制度与木卫四载人任务都属于假设，不能当作已发生事实。长期低重力生活、辐射防护和生育安全没有被本牌组宣布解决；没有成熟聚变、瞬时通信、露天宜居或必然盈利的捷径。

不强行加入占星、希伯来字母与卡巴拉对应，以免把不同传统的对应表混为唯一经典。保留大阿卡纳原型，不把心理学启发写成荣格亲自制定了这套火星牌义。
