## 怎么读

1. 开场共同读[共同背景](01-共同背景/00-共同背景.md)，主持人说明本局起点与结局约定。
2. 选身份后只读对应的一页知识卡，不必读完全部文件。
3. 家园抽到主题后先自由讲述，相关背景按需阅读，自然联系前史，不强制解题；远航抽到课题后读相应情境条，接续前幕决定。

## 证据标签与使用边界

- **事实／观测**：已有资料支持，仍须注意地点和条件。
- **技术演示**：只支持已演示的系统、规模与环境。
- **尚不确定**：不能默认风险已经消失，也不必写成必然失败。
- **本局假设**：未来机构、能力、态度和具体事件，需要桌上说明。
- **工程约束／推论**：帮助检查前提，不是实际火星城市的统计或价值判断。

不靠资料卡自动获得能力；新增供给、协作与授权需要相关方确认。出现争议可回查来源、标为待验证或调整本局假设。
