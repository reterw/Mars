# 家园时代｜向内重构

## 从“据点能运转”到“人怎样共同生活”

假设经过长期积累，城市已能通过设施和组织应对日常外部危险，但低压、辐射、尘暴与供给约束并未消失。讨论从建设生存能力，转向这些条件下逐渐展开的社会生活。

七张牌提供宽主题，不是七道治理题。具体社会问题藏在背景中，参与者也可以谈美好、趣味与新可能。

## 怎样开启讨论

**围绕这张牌，讲讲你想象中的火星生活。可以从你的经历、事业、愿望，或一个突然想到的故事开始。**

不必逐项回答，不要求专业知识、解决方案或共同结论。身份是观察位置，不是答题岗位；可以自然接续第一时代的决定，也可以描绘事业延续后出现的新生活。

先自由表达，再按意愿留下故事、愿望、分歧或下一步方向。主持人不急于把话题收束成工程和制度方案；科学背景按需读，正逆位仅供参考。

## 当前玩法

本组是第二时代的主题牌池，不是身份牌。每人从力量至节制有放回抽取，允许重复，原有身份与事业延续。具体时间与共同边界以当前流程为准。
