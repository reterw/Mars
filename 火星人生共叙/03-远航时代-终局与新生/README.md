# 远航时代｜终局与新生

## 从“我们怎样生活”到“我们要把怎样的文明带向远方”

终局回望我们成为了怎样的文明，也打开不同的未来走向。恶魔是困住，塔是打破，星星是重启，月亮是看不清，太阳是让人生在猩红世界扎根与绽放，审判是行星文明在差异中的重新交融。它们不是必须依次发生的剧情，也不是自动生效的固定结局。审判打开跨行星联结与共同身份的讲述，世界作为木卫四共同尾声；留守、修复与照顾家园同样有意义。

## 当前共叙使用

保留身份与事业，从恶魔至审判有放回抽取，允许重复；世界不进入个人抽题池。六张均以开放讲述接续前两时代；审判不强制统一、和解或形成共识。不是每张都要成为远征任务，也不要求先毁灭再获救。
