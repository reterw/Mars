# 科学背景与来源

## 如何读“硬核背景”

本组优先复用项目既有[23张主题卡及其统一来源](../docs/火星时代自由麦-历史切片样卡.md)，不把旧资料的核查日期改写成本次重新核查。来源编号S沿用该文，便于追溯；J01为木卫四新增入口。卡中C编号指主题，不是外部来源。下表只是本组用到的入口，不复制整套资料。

每张卡都分开写：

1. **事实／观测**：如火星日长、光行时、特定着陆点的冰与盐类记录。
2. **限定条件的技术演示**：如MOXIE、ISS水回收、轨道种植；跨环境、跨规模外推要另行验证。
3. **工程推论或设计约束**：如气闸影响可达性、共因失效、系统更新需验证；不是某座真实火星城市的事故统计。
4. **未来设定／价值选择**：城市、职业制度、产权、远征及结局均为创作；科学说明限制条件，不替人作价值选择。

## 特别容易画错或讲过头的地方

- 火星日比地球日长，不是固定多出一段可随意填满的“免费工作时间”。
- 低重力长期健康和心理支持是不同证据链；地球模拟研究不同时验证两者。
- 大范围尘暴会影响光照与运营，不照搬地球飓风把人或大车卷走的力学画面。
- 火星全年并非都单程延迟22分钟；“约3—22分钟”是传播量级，不包括一切处理等待，也不能直接用于地球—木卫四通信。
- 太阳牌的44%是以平均日距和平方反比关系估算的大气层外辐照比例，不是太阳能板实际输出率。
- 第三组的木卫四载人登陆为用户指定的故事终点，沿用[既有剧本](../剧本/剧本v1.md)的独立论证边界；不宣称从火星走一定更省，不填写未经验证的推进、航程、辐射剂量、轨道或预算。
- 木卫四的潜在地下海洋不是已探明矿泉，也不是露天海洋。即使任务假设实现，登陆仍不等于殖民、宜居或经济闭环。
