## 编写与使用说明

- 卡面由共同身份、两个时代下各三个地点的情景、开放邀请组成；不预填答案或解决办法。
- 身份提供观察位置，可以代入，也允许旁观、评论或质疑，不要求表演。
- 身份不只包含职业，亦包含亲友及公共生活中的参与者。
- 每卡标注时代、地点适配说明；不兼容时换卡，不强迫圆故事。
- 所有未来载人生活情景均为活动假设，不是已经发生的事实。
- 关联的原主题卡作为备用资料，不要求逐项回答。
