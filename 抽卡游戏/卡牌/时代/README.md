# 时代卡组

> 两时代讨论版。原“远行”“驻留”合并为T01，原“家园”改编号为T02；旧编号不再沿用。均为活动假设，不对应确定年份、人口或必然的发展路线。

## T01｜探索与驻留时代

**卡面背景**：已有载人往来与火星驻留。人们为了任务前往火星，并建立、维持基地；生活主要围绕任务组织，关键支持依赖地球。

- 不把场景限定为首次抵达，也不强制设定基地已稳定运行多年。
- 探索、建设、轮换与维护可以并存；具体任务由后续卡片补充。
- 人们有工作之外的生活，但长期驻留不等于永久定居。

完整样卡：[T01｜探索与驻留时代](T01-探索与驻留时代.md)。

## T02｜家园时代

**卡面背景**：火星成为一些人的长期家园。人们不仅讨论如何完成任务，也开始决定怎样生活、共同安排未来。

- 公共空间、教育、照护、文化与共同规则可以成为生活的一部分；具体设施和能力不默认全部实现。
- 火星也可能成为进一步远行的出发地，但深空任务是可讨论的计划，不是本时代自动具备的能力。
- 家园不等于完全自给、可以露天生活，也不意味着人人愿意永久留下。

完整样卡：[T02｜家园时代](T02-家园时代.md)。

## 使用说明

两个时代均可组合三个地点。时代提供共同背景，地点进一步描述环境，情景再补充人物与眼前的事情。

关键差异是“为了任务去那里”与“把那里作为家园安排人生”，不是简单区分基地大小或自给比例。两个时代不必依次通关，也不保证从前者发展到后者。
