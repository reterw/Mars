# 地点卡组

> 三张地点牌均已补齐两个时代分支。先读共同特性，再读已抽时代对应的段落；具体人物与眼前的事情留给情景牌补充。

完整卡面：
- [L01｜在地球上](L01-在地球上.md)
- [L02｜在火星上](L02-在火星上.md)
- [L03｜在地火之间的旅程中](L03-在地火之间的旅程中.md)

## L01｜在地球上

事情发生在地球这一端。可以是家中、工作场所、出发港或公共空间，不限定为任务控制中心。

地球上的人有自己的生活、选择与观点，不只是远行者的后勤支持。

## L02｜在火星上

事情发生在火星。具体场景须符合抽到的时代：探索与驻留时代的任务基地，或家园时代的长期居住地，不默认成熟城市已经存在。

这里的载人活动均为未来假设，不把火星室外当作可以直接呼吸和自由生活的地球街区。

## L03｜在地火之间的旅程中

事情发生在地球与火星之间的航程上。可以是去程，也可以是返程；具体方向由发言者说明。

旅程不是瞬间抵达，也不默认可以随时返家或与两端即时通信。
