# 火星抽卡游戏

> 初始讨论版：2026-10-29。作为后续迭代基础，不替代既有开放麦资料，也不是最终规则。

## 核心结构

每次从三个卡组各随机抽一张，组合成一个处境：

**时代 × 地点 × 情境（人物与事件合一）**

面对这个处境，参与者自由回应。可以表达观点、经验、故事、作品设想、研究问题、做法或反对理由；不要求角色扮演、解决问题、达成共识或给出标准答案。

连读示例：T01全文 → L01的共同特性与T01段落 → S05的共同身份与T01／L01段落 → 开放邀请。其他分支不读、不叠加。

## 基础玩法草案

1. 三个卡组分别洗牌，各抽一张。
2. 先读时代背景；地点牌按已抽时代补充环境；情景牌按已抽时代与地点补充人物及眼前的事情。后一张继承前面的条件，不重新设定背景。
3. 用一句开放邀请开始：**“在这个时代、这个地方，发生了这件事。你有什么想说的？”**
4. 参与者自由回应，其他人可以接麦。

发言时长、换卡方式、是否按时代分轮暂不固定，留待试玩迭代。若组合存在明显冲突，可先换一张，不强迫参与者圆故事。

## 编写边界

- 两个时代是活动中的未来假设，不是预测，也不保证依次实现。
- 时代交代生活背景和能力边界；地点只决定观察位置，不指定职业或身份。
- 情境卡不全是危机，也保留日常、庆祝、变化、探索与争议。
- 情境中的人物不是参与者必须扮演的角色，允许代入、旁观、评论或质疑。
- 无论抽到哪个地点，人物与情景都应服务于或关于火星活动及其影响；允许批评、质疑或反对，不等于必须支持计划。
- 通过对应时代、地点的分支增加特性，而不是让所有组合共用一段泛化情景。新增能力应明确标为活动假设，不与前牌冲突。
- 共享事实，不强迫共享价值；创作、假设与科学事实分开说明。
