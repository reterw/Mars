# 四时代火星商业游戏：试玩流程草案

> 整理日期：2026-10-23｜讨论稿，尚未试玩验证
>
> 本文整理本次讨论认可的游戏方向与现场流程，不是完整规则书。公司初始能力、项目投入产出、采购评选、事件效果和胜负计分仍需设计。文中的时间、数量与筹码均为试玩参数，不是火星工程或经济预测。

## 一、活动定位

**同一批公司，经历四个时代，通过投资、谈判、联合建设与履约，共同塑造火星的发展。**

玩家不是单纯讨论“火星应该怎样发展”，而是在具体约束下决定：我做什么、与谁合作、承担什么风险，以及把什么代价留给别人。

- 参与人数：10—12名玩家，主持人另计。
- 席位原则：一人代表一个独立组织，不设置多人共用席位，也不让一人兼任多个组织。
- 组织类型：以公司为主，可包括提供资金的投资机构。具体名单与能力分配待设计，不直接照搬现有叙事剧本的组织席位。
- 活动时长：150分钟。
- 核心玩法：公司谈判＋联合建设＋项目竞标＋运营事件。
- 体验重点：合作与竞争、有限资源取舍、投资的长期后果，而非复杂记账。

每个时代都重复同一套流程，让玩家在熟悉操作后，把注意力放在局势和合作关系上。

## 二、贯穿全场的规则原则

### 1. 公司状态不清零

四个时代不是四场独立小游戏。公司资金、资产、有效合同、履约记录与维护负担持续保留，已建设施会影响后续项目。

### 2. 公司经营与火星发展分开呈现

- **公司账：**现金、资产、履约情况，以及战略目标完成情况。
- **火星账：**已建能力、关键短缺、地球补给依赖、可靠性和居民处境。

公司赚钱不等于火星整体发展良好。具体公司排名与计分方法待设计，不把两本账简单相加成一个总分。

### 3. 时间切幕，不自动解锁能力

为了控制现场时长，四幕按时间表切换；但能力不会因为进入下一幕而自动获得。

如果前期缺少电力、运输或维修能力，下一幕就必须补建、缩小项目或选择其他行动。未满足条件的高级项目继续锁定，不能用“多年以后”跳过缺口。

本草案使用的是固定四幕结构，与早期活动设计中“能力未达标就停留在同一时代”的设想不同。这里的时代是议题与需求阶段，不代表玩家必然完成了对应发展等级。

### 4. 合同依赖自愿承诺

全场投票不能强迫某家公司提供资金、技术或服务。涉及公司的合同必须得到相关玩家确认。

公共采购按预先公布的标准评选；公司自建项目不需要全场投票，但必须满足资源和建设条件。

### 5. 不让玩家整轮无事可做

公司没有拿到新项目时，仍可以经营现有设施、提供服务、储备资源、预订运力或为后续项目做准备。正式规则需要给这些行动可执行的选项，避免某家公司成为不可替代的“钥匙”，也避免有人长期旁观。

## 三、四个时代

| 时代 | 核心问题 | 候选项目 | 前期选择留下的影响 |
| --- | --- | --- | --- |
| 第一时代：生存前哨 | 有限运力先送什么，扩张与可靠性如何取舍？ | 卸货、供电、维修、仓储 | 初始设施、备用能力与补给依赖 |
| 第二时代：本地立足 | 怎样把当地资源变成可交付的产品？ | 取冰、制氧、建材、地面物流 | 产能、电力需求与基地空间布局 |
| 第三时代：定居社会 | 怎样让人长期生活，服务是否可负担？ | 农业、住宅、医疗、公共服务 | 生活条件、维护负担与服务保障 |
| 第四时代：深空支点 | 改善本地生活，还是投入远航业务？ | 制造、轨道服务、远航补给 | 最终发展路径，以及仍未解决的依赖 |

以上项目是候选方向，不是每幕必须全部开放的清单。第一版每幕只新增2—3个项目、使用1个事件，关键资源最多保留4种。

第四时代的深空项目不是必达结局；缺少前置能力时，继续改善火星本地服务也是有效选择。

## 四、全场时间安排

| 环节 | 时长 |
| --- | --- |
| 开场、角色与规则演示 | 20分钟 |
| 第一时代：生存前哨 | 25分钟 |
| 第二时代：本地立足 | 25分钟 |
| 第三时代：定居社会 | 25分钟 |
| 第四时代：深空支点 | 25分钟 |
| 终局结算与复盘 | 20分钟 |
| 全场缓冲 | 10分钟 |
| **合计** | **150分钟** |

缓冲用于规则澄清、转场和结算延误，不预先安排额外事件。

## 五、开场流程：20分钟

### 主持人介绍共同处境

展示火星基地地图、已有设施和当前短缺，用一个具体问题开局：

> 渡口站能够维持，但运输与维修能力有限。下一批物资既有人想用于扩建，也有人要求先增加可靠性。所有需求不能同时满足。

### 玩家领取材料

- 公司卡：现有能力、可提供的服务与行动边界。
- 初始资金和能力标记：具体配置待平衡。
- 秘密战略目标：鼓励不同经营方向，不奖励破坏生命支持或故意制造事故。
- 全场共用的流程与合同说明。

秘密目标可以围绕客户覆盖、可靠供应、设施投资等方向设计，但不能成为玩家隐藏的工程能力或虚构资源。

### 演示一次建设与运营

用一个小例子说明：建设温室不仅需要建设资金，还要有设备运输、水和电。付了建设费不等于已经有稳定产出。

同时区分投资意向、正式承诺和实际交付，避免玩家把口头讨论当成已经生效的合同。

## 六、每个时代的标准流程：25分钟

**看机会 → 同时亮投资意向 → 自由谈判 → 锁定方案 → 事件与补救 → 运营结算。**

### 第一步：看机会，3分钟

主持人公布：

- 当前设施、可用能力与关键短缺；
- 本幕采购需求和2—3个新项目；
- 运输容量等稀缺资源；
- 一个公开风险预警。

项目卡提前摆好，不在现场逐条朗读长篇背景。玩家应能看出客户是谁、前置条件是什么、哪种风险值得防备。

### 第二步：同时亮投资意向，2分钟

每家公司秘密选择一个主要方向，再同时公开。

它用于暴露行业判断：可能有多家公司想建温室，却没有人准备供水。此时只公开意向，**不正式扣款，也不算签约**。

亮牌后允许调整；调整是否需要付出代价及其大小，待规则设计时确定并提前说明。

### 第三步：自由谈判，8分钟

玩家寻找客户、供应商、投资者与联合建设伙伴。

典型谈判包括：

> “我提供运输，但需要预付款。”
>
> “我们共同建电站，但我要优先供电的额度。”
>
> “你先拿到采购合同，我才愿意出建设资金。”

联合项目讨论的不只是支持与反对，还包括投入、收益、服务优先级与责任。谈不成时可以缩小规模、换合作方，或选择不进行本轮新投资。

### 第四步：锁定方案，4分钟

相关公司提交并确认简短合同，至少写清：

1. 交付什么，数量和期限是什么；
2. 谁向谁付款，何时支付；
3. 依赖哪些供给与前置条件；
4. 未履约时怎样处理。

主持人按事先准备的检查表核对资金、运力、建设与运行条件；同一份资源不能被重复承诺。

公共采购按预先公布的标准评选，规则需事先说明超额需求与并列结果的处理方式。通过检查后，资金和运输位置才正式锁定。

### 第五步：事件揭晓与限时补救，4分钟

揭晓一个与当前状态匹配的事件，例如设备交付延误、部分设施故障或供能受限。

- 按预写规则确定影响，不临场凭感觉扣钱或判罚。
- 同一事件根据公司配置产生不同后果，库存、冗余和替代供应应当有价值。
- 没有建设的设施不会发生对应事故。
- 给玩家一次限时补救机会，可以追加采购、缩小运营规模或协商延期。
- 补救不能抹去已经发生的损失，也不能凭空获得设备和能力。

事件效果与补救选项必须提前准备，避免四分钟变成漫长的自由裁定。

### 第六步：运营结算，4分钟

先检查供能、供水、运输等依赖，再计算实际交付与收入，更新设施、资金、履约记录和持续负担。

如果本幕新建设施能在本幕运营，项目卡必须明确建设期已被本幕抽象时间覆盖；否则只能在后续幕产生收益，不能默认瞬间建成。

主持人同时发布火星发展简报，例如：

> 温室投入运行，但居民仍依赖进口食品；备用电源让本轮供能波动没有扩大为食物危机。

简报应对应实际结算，不能用叙事额外赠送产能。

## 七、第二时代示例：订单有了，电不够

> 本例展示决策结构，不规定正式数值或必然剧情。

1. 桌面开放取冰、电站和温室项目，但运力不足以让所有项目同时完整建设。
2. 同时亮牌后，发现取冰与温室受到追捧，供能配套不足。
3. 取冰公司与温室公司有合作意向，但需要向能源公司争取供电。
4. 玩家可选择增加供能投入、缩小取冰规模、推迟温室，或换成另一套可行方案。
5. 正式锁定后揭晓供能事件，按实际配置影响产出。
6. 提前准备备用能力的公司受损较小；缺少保障的公司需要限时采购、减产或履行合同约定的延期处理。
7. 本幕形成的设施与未完成建设继续留到下一幕，不能结算后重置。

娱乐性来自玩家选择互相碰撞，以及他们如何在有限条件下补救，而不是让主持人刻意制造失败。

## 八、真实性与娱乐性的分工

### 真实约束负责让取舍有意义

- 地点、季节与尘埃条件影响供能，不能只看装机容量。
- 水冰线索不等于可立即开采，取冰需要勘探、设备、能源与物流。
- 低温、稀薄大气与压力条件影响设施和运行需求。
- 地火运输受轨道、航程与任务安排约束，不能默认有随叫随到的加急补给。
- 维修与本地自主处理能力有价值，不能默认地球实时遥控救场。

每张项目卡优先展示：**投入、产出、前置条件、运行限制**。后台保持统一的时间段、数量单位和资源收支，前台使用易计算的资源单位。

### 明确三类数据

| 类型 | 使用原则 |
| --- | --- |
| 环境事实与观测资料 | 标注来源、地点、时间与证据边界 |
| 工程估算 | 说明设备与运行条件，不当作普遍常数 |
| 游戏假设 | 明确标记未来价格、筹码、建设周期、事件概率与平衡数值 |

既有研究可从[研究资料目录](research/README.md)查找。引用研究不意味着项目投入产出已经完成校准。

### 游戏机制负责制造戏剧性

有限运力让玩家取舍，同时亮牌让预期碰撞，联合项目让合作与分配产生张力，事件与补救让准备接受检验。

第一版不引入股票市场、复杂贷款、任意自由合同和逐小时仿真，也不让AI自由决定收益或事故后果。

## 九、终局与复盘：20分钟

### 展示公司结果

展示现金、资产、履约记录和秘密目标完成情况。正式排名方式尚待确定，试玩时不临场发明计分规则。

### 展示火星结果

- 建成了哪些能力，哪些仍是短板？
- 减少了哪些地球补给依赖，又新增了哪些维护需求？
- 哪些设施或服务过度依赖单一公司？
- 居民得到了什么，又承担了什么代价？
- 深空业务是否具备条件，还是本地需求仍应优先？

### 玩家简短复盘

每人围绕一个问题发言：

> 我最成功的一笔投资是什么？我把什么代价留给了别人？

结局不预设必须远航成功。设施布局、经营关系和未解决问题共同构成这场游戏的火星历史。

## 十、试玩前仍需完成的准备

本文确定流程，不代表已可直接开场。至少还需完成：

- 10—12个组织的公司卡、初始资源与不依赖新项目的可选行动；
- 全场最多4种关键资源的定义、单位和结算顺序；
- 每幕2—3张项目卡及其客户、投入产出、建设时间和维护负担；
- 采购预算、评选标准、并列与资源冲突处理规则；
- 简短合同模板、违约处理与资金不足时的持续参与办法；
- 每幕事件、预警、效果及可执行的补救选项；
- 公司结果的计分或比较方式，以及火星发展展示板；
- 一次主持人桌面试算，检查25分钟能否完成一幕。

**首轮验证重点：玩家能否谈成合作、主持人能否快速结算、结果能否影响下一幕。** 如果结算经常超过4分钟，优先减少合同和资源复杂度，而不是继续增加规则。
