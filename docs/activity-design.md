# 火星未来发展讨论与互动活动：设计草案

> 版本：v0.1｜整理日期：2026-10-05
>
> 本文记录当前讨论成果，不是最终规则书，也不是火星发展预测。明确共识、候选机制和待研究问题分别标注；示例数值仅用于说明玩法，尚未校准。

## 1. 活动定位

以火星未来发展为主题，结合科学资料、简化仿真、集体讨论、匿名投票和随机事件，共同推演一个火星社会的发展历程。

活动希望营造类似远航前水手讨论新大陆未来的氛围，但以现实主义为指导：既讨论如何生存、生产和扩张，也讨论人类到了火星之后依然要面对的管理、心理、经济、技术与社会问题。

核心问题不是“怎样最快殖民火星”，而是：

**在真实约束和不确定性下，我们把有限资源投入哪里，最终创造怎样的火星社会？**

- **参与规模：**约10—12人，来自管理、心理、经济、计算机、物理、生物等不同领域。
- **活动时长：**共2.5小时，即150分钟。
- **活动根基：**一个追踪火星发展关键状态、能够推进模拟时间的仿真器。
- **体验重点：**跨专业交流、公共选择及其代价，而非精细经营或单一数值竞赛。

## 2. 当前已经明确的设计共识

1. **以能力里程碑划分时代。** 使用粗略、层级分明的能力描述，避免为了全面而增加过多指标和操作。
2. **轮次不等于时代。** 一轮结束不保证升级；必要能力尚未满足时，继续处于当前时代。
3. **政策、投入与事件影响发展时间。** 在“长期目标最终能够达到”的游戏叙事前提下，重点观察它们如何加速或延后里程碑，以及留下什么代价。
4. **先理解时代，再决定行动。** 每轮应先介绍当前状态与现实研究，再讨论这一时期最值得注意的问题。
5. **选择有得有失。** 看似合理的决定可能在特定事件下暴露弱点；不能简单把选项分成正确和错误。
6. **参与者能够提出方案，最终匿名投票。** 具体提案、合并和投票办法尚待确定。
7. **按时代组织卡牌。** 当前更倾向于“发展方向卡”，通过多个方向之间的资源投入分配影响结果，而不只是选择一条政策。
8. **科学是边界，AI裁定是候选工具。** 将仿真数据及其他资料输入AI辅助判断影响，是当前设想，后续可以修改。

“目标最终能够达到”是活动的叙事设定，不是科学保证；也不意味着活动结束时必须达到最后一个时代。

## 3. 时代与能力等级：候选框架

最初的直觉是沿着“依赖地球输送 → 本地产能逐步接近地球输入 → 自主发展 → 对外提供产能 → 成为深空探索支点”展开。

为了简化呈现，同时避免把不同物资混为一谈，建议以可实现的能力定义等级，而不直接把“火星产能与地球输送产能之比”作为唯一门槛。建材、水、食物、关键备件之间不能任意替代。

| 等级 | 时代名称 | 大致能力画像 | 适合讨论的问题 |
|---|---|---|---|
| Ⅰ | 生存前哨 | 支持短期驻留；食物、设备和关键备件主要来自地球 | 为什么来？谁能来？谁承担风险？ |
| Ⅱ | 本地立足 | 能稳定获取部分水、制氧并生产基础建材；关键补给仍依赖地球 | 优先扩张，还是增加安全储备？ |
| Ⅲ | 定居社会 | 能生产相当部分食物、维护常用设施，支持长期社区 | 如何安排劳动、教育、健康、分配与治理？ |
| Ⅳ | 工业自治 | 大多数日常物资可本地生产；部分高科技设备仍可能依赖地球 | 谁掌握关键设施？自主意味着什么？ |
| Ⅴ | 深空支点 | 有余力为后续深空任务提供部分补给、制造或维护服务 | 如何平衡居民生活与进一步探索？ |

以上是玩法分级建议，不是已验证的技术发展路线；具体门槛和先后关系需要后续研究。

### 等级设计原则

- **等级表示能做什么，不表示社会有多好。** 工业能力很强，不等于生活幸福、分配公平。
- **升级取决于必要条件，而非总分。** 能源富余不代表食物和维修能力已经达标，不能靠无限投入一个方向绕过其他瓶颈。
- **人口规模是问题显现的背景之一。** 不同人口与生产规模可以触发新的议题，但暂不设未经研究的精确人口门槛。
- **不强制以向地球出口大宗物资为必经阶段。** 其经济性有待验证；为轨道设施和深空任务服务是另一种候选终局路径。

## 4. 轮次、时代与模拟时间

需要区分三个概念：

| 概念 | 含义 |
|---|---|
| 活动轮次 | 现实中一次完整的介绍、讨论、投票和结算 |
| 当前时代 | 仿真中的能力等级；可能连续多轮保持不变 |
| 模拟时间 | 火星发展经过的时间；政策和事件可能改变后续里程碑到达时间 |

建议的循环为：

**读取当前状态 → 理解时代问题 → 提出并分配投入 → 匿名投票 → 掷骰确定事件 → 结算影响 → 推进仿真并检查门槛。**

若未达到升级条件，下一轮仍使用当前时代的议题和可用方向，但必须反映累计建设、已经发生的事件与新的瓶颈，而不是从头开始。

### 时间机制仍需确定

目前没有决定每轮对应多少模拟时间，也没有决定：

- 按固定时段推进，然后检查是否升级；
- 或根据行动结果估计达到下一个里程碑还需要多久，并在约定决策节点停下。

无论采用哪种方式，都应保留“未达标可以停留在同一时代”的机制，不能通过直接跳到下个里程碑变相保证每轮升级。

比较“提前或延后”时，需要明确同一当前状态下的参考计划，避免把不同轮次、不同前提的时间估计混在一起。参考计划的具体算法尚待设计。

## 5. 从政策卡到发展方向卡

### 当前倾向

一轮存在多个可投入方向，参与者决定资源如何分配，而不只是投票选择一个互斥政策。

政策仍然可以存在：发展方向回答“优先做什么”，政策回答“怎么做、由谁承担、怎样分配”。是否将两者分成两类卡牌，尚未确定。

### 卡牌的时代归属

每张卡标注：

- 可用时代及必要前提；
- 方向或措施，以及希望解决的问题；
- 投入需求与大致生效速度；
- 主要收益、代价和风险承担者；
- 可能持续到后续轮次的影响。

为控制阅读负担，卡面尽量只显示“一句措施、主要变化、一个长期标签”；较详细的裁定说明留在主持人或仿真器端。

### 示例：本地立足时代

| 发展方向 | 主要作用 | 需要考虑的取舍 |
|---|---|---|
| 扩大能源供给 | 为后续生产与扩建提供条件 | 当期占用建设资源，且收益可能滞后 |
| 发展本地生产 | 减少部分补给依赖 | 依赖设备、能源和维护能力，未必立即见效 |
| 增加储备与冗余 | 降低事故和补给失败造成的延期 | 减少当期用于扩建的资源 |
| 改善社区生活 | 回应长期驻留的身心与组织问题 | 占用有限资源，收益不能完全用产量衡量 |

这些是示例方向，不是正式平衡后的卡组。

### 候选资源分配机制

- 每轮开放3—4个方向。
- 用10枚投入筹码表示当期可调配预算。
- 参与者可以提出分配方案，相似方案合并。
- 最终保留2—3个候选方案，通过匿名投票选出一个完整的资源分配方案。

以上数量均为待试玩参数。筹码是界面抽象，不代表能源、设备、运输与人力可以无条件互换；后端仍应检查可行性和前置条件。

## 6. 仿真器的简化呈现

原则是：**把必要复杂度留在后台，让参与者看到时代、能力、选择和后果。**

一个候选前台方案是使用三个5格状态条：

| 状态 | 粗略含义 |
|---|---|
| 生存保障 | 储备、冗余与应急能力 |
| 发展能力 | 建设、生产和技术积累 |
| 社会状态 | 居民福祉与合作状况的粗略代理 |

这套面板尚未确定。尤其是“社会状态”不能伪装成客观、精确的社会科学测量，也不能掩盖不同群体之间的差异。

仪表盘之外，应保留简短文字反馈，例如“维修负担增加”“某类居民承担更多风险”“生活改善尚未惠及所有人”。

状态条用于概览，时代升级则依赖必要能力的检查。具体后台指标、因果关系和阈值尚未设计。

## 7. 随机事件：改变处境，不抹掉因果

保留参与者掷骰触发事件的设想，事件可以有利，也可以不利。

候选机制是每轮只掷一次事件骰，从当前时代的预设事件表取结果，再由已有投入、状态和长期标签修正影响。

例如，同样是补给任务失败：

- 储备充足时，可能只是建设延期；
- 储备不足时，可能需要缩减活动甚至撤离部分人员。

设计原则：

- **灰犀牛要有预警。** 已知而被忽视的风险，应能在之前的简报中看到。
- **黑天鹅少量出现。** 不应让随机性压过参与者的全部决策。
- **准备应当有价值。** 同一事件在不同发展路径下应产生不同后果。
- **正面事件同样需要承接条件。** 获得机会不等于自动兑现收益。

事件种类、概率与影响范围均待设计。

## 8. AI辅助判断：当前设想与边界

### 当前设想

将仿真数据、投入方案、事件和相关研究资料输入AI，请其辅助判断对发展进程的影响。该机制尚未定型，也不排除改用固定规则或混合方案。

### 建议输入

- 当前时代、能力与状态；
- 已有设施、历史投入及持续影响；
- 本轮资源分配和随机事件；
- 时代门槛及参考发展计划；
- 有来源的研究资料，以及明确标注的游戏假设。

### 建议输出

1. 哪些能力发生变化，哪些作用存在延迟；
2. 当前最重要的瓶颈是什么；
3. 相比参考计划，里程碑提前还是延后；
4. 判断依据、关键假设和不确定性；
5. 哪些后果无法可靠量化，需要文字呈现或人工裁定。

### 建议约束

第一版可以先输出“明显提前／略提前／基本不变／略延后／明显延后”，再由公开规则映射为时间调整。映射尺度尚未确定，不能把它当作科学推算。

AI适合解释、检查遗漏和辅助推演，不宜在缺乏依据时自由生成精确年份或任意改变数值。可考虑“仿真器负责确定性约束，AI负责受约束的解释与建议，主持人处理争议”的分工。

实际活动还需要无需等待AI的备用结算办法，以免网络、响应延迟或裁定分歧打断节奏。

## 9. 科学边界

需要区分：

| 类型 | 在活动中的处理方式 |
|---|---|
| 科学与工程约束 | 用于限制可行选择，不因投票或AI判断而取消 |
| 尚未确定的技术前景 | 明确假设或范围，不当作已经实现的能力 |
| 社会反馈假设 | 用于讨论和简化推演，承认其不确定性与价值取向 |
| 游戏抽象 | 为控制时长而采用的刻度、筹码和标签，明确不是科学测量 |

后续优先核实的主题包括：地火运输窗口与运输能力、定居点选址、本地水与氧气获取、能源、规模化生产、食物与生命支持、维修及关键设备依赖。

例如，常规低能耗地火发射机会大约每26个月出现，补给不能被处理成随叫随到；但正式规则还需要区分发射窗口、航行时间、运力与库存，而不是只使用一个周期数字。

本文是讨论纪要式设计草案，未进行独立文献核查。正式时代简报和卡牌应补充来源、适用范围及证据边界。仓库已有资料可从[研究资料目录](research/README.md)进入，但其内容仍需进一步筛选并转化为活动规则。

## 10. 150分钟活动安排：候选版本

| 环节 | 时长 |
|---|---:|
| 背景、科学边界与规则说明 | 15分钟 |
| 四轮讨论与决策，每轮25分钟 | 100分钟 |
| 终局展示与复盘 | 25分钟 |
| 机动时间 | 10分钟 |
| **合计** | **150分钟** |

每轮25分钟的候选拆分：

| 环节 | 时长 |
|---|---:|
| 当前时代与仿真状态简报 | 3分钟 |
| 写卡、提出并合并分配方案 | 5分钟 |
| 讨论 | 10分钟 |
| 匿名投票 | 2分钟 |
| 掷骰、结算与后果叙事 | 5分钟 |

**四轮是现实时间预算，不是四次保证升级。** 五个等级是完整发展框架，一场活动不一定经历全部等级。

### 发言安排尚未确定

原始设想是每人全场有2—3次机会发言影响政策。

另一个候选方案是允许常规简短发言，把2—3次限制改为“正式提案、修正或要求复议”的特别权力，以免过早消耗发言机会阻碍跨专业交流。

最终形式需要结合10—12人的规模试玩，确保每轮讨论能在10分钟内结束，并让不同参与者都有参与机会。

## 11. 终局与复盘

不建议用唯一总分宣布哪一种社会最正确。终局可以展示：

- 到达了哪个能力等级，经历了多少模拟时间；
- 哪些决定加速或延后了关键里程碑；
- 生存韧性、生活质量与自主程度如何；
- 谁受益、谁承担代价，有哪些分配和治理问题；
- 留下了哪些长期风险或发展机会。

终局要回答的是：

**我们用了多久走到这里？创造了怎样的火星？为了这条路径付出了什么？**

## 12. 下一步需要确认的事项

1. 确定时代划分及每个时代少量、清晰的必要能力门槛。
2. 确定轮次如何推进模拟时间，以及提前／延后的比较基准。
3. 确定方向卡与政策卡是否分开、资源投入怎样影响收益。
4. 确定匿名投票规则、平票处理与发言安排。
5. 确定AI、固定规则和主持人的裁定边界。
6. 选一个时代做完整试玩，验证提案、讨论和结算能否在25分钟内完成。

最小原型可以先由一张状态面板、一份时代简报、3—4张方向卡和一张事件表组成。先验证讨论与反馈是否有效，再决定仿真器需要多复杂。
