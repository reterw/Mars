## 2. 核心结论

### 2.1 应研究“完整食物系统”，而不是只研究“火星上能不能长出植物”

能够发芽、长叶、产生淀粉、形成菌体，与长期供应安全、足量、营养完整的饮食是不同目标。系统至少需要同时保证：

- 可摄入的能量，而非仅有鲜重产量；
- 蛋白质和必需氨基酸；
- 油脂及必需脂肪酸；
- 维生素、矿物质、纤维和饮水；
- 可接受的口味、加工、储藏与卫生；
- 在歉收、污染、断电和补给延误时仍可维持的库存。

“生菜＋淀粉”不是完整菜单；普通作物组合也不是可靠的 B12 来源。营养强化、补充剂及其保质期应当进入初期方案，而不是被视作失败。[02：A13–A18、A20]

### 2.2 原位资源利用必须经过“勘查—提取—净化—验收”

火星具有可利用的碳源、水资源线索以及多种矿物元素，但不能直接把外界环境当作温室：

- 大气含 CO2，不等于有适宜植物的压力和环境；
- 存在冰，不等于已经证实可采储量、覆土条件和连续产水能力；
- 样品含磷、钾、氮，不等于能直接制成作物营养液；
- 存在高氯酸盐等污染问题，矿水和风化层不能未经处理进入食物链。

建议把早期农业根区与未经处理的火星风化层分开，先使用可控营养液或经过验证的基质；本地养分提取作为单独的研究和设备模块。[01：R08–R12；02：A08、A11]

### 2.3 没有证据支持一个“营养最好的火星地区”

对于密闭受控农业，人员营养更多由菜单、作物或菌株、培养配方、加工储藏决定。场址主要决定水源、电力、温控、施工和物流成本。

| 区域方案 | 值得研究的理由 | 不应跳过的验证 |
|---|---|---|
| Arcadia Planitia 中纬候选带 | SWIM 的重点研究背景，适合开展浅冰综合证据筛选 | 具体地点的冰顶埋深、连续性、覆土和设备可达性 |
| Utopia Planitia 富冰研究区 | 有厚层雷达反射和含冰解释 | 厚度不是覆土；区域冰体积不是日净水产能 |
| Deuteronilus Mensae | 碎屑裙具有主要由冰构成的雷达证据 | 地形、覆盖层、钻进和运输条件 |
| 较低纬对照方案 | 可比较较有利的季节供光条件 | 水源不确定性、结合水提取负荷或远程供水成本 |

这里列的是**区域研究方案，不是最终登陆点排名或已确定坐标**。下一步应在统一季节、设备和能源假设下，叠加 SWIM、MOLA、气候与高分辨率影像，再安排地面勘查。[01：R01–R07、R16–R18]

### 2.4 CO2 转淀粉值得追踪，但不能直接作为首批人员的唯一口粮保障

2021 年 Cai 等的 Science 论文报告了以 CO2 和 H2 为起点、包含 **11 个核心反应**的无细胞化学—酶催化路线。摘要中的约 **8.5 倍**比较针对其定义的合成速率，**不是整厂能效、亩产或成本优势**。[03：C01-01]

进一步工程化仍需要解决电力、氢气、酶制造与寿命、辅因子、分段工艺、食品级净化和维护。甲醇、甲醛是受控工艺中间体，不是可直接食用产品。本轮未取得原始论文全文及补充材料，因此不提供未经核实的整线产率、工厂电耗或成本。[03：C01-01–03、C01-17]

对仿真器而言，这条路线适合作为**有实验依据、关键工程参数尚缺的研发分支**。启用前必须声明情景假设，不能因技术名称已存在就默认具有可靠量产能力。

### 2.5 微生物蛋白是另一条重要路线，但并非“只有空气就能造饭”

氢氧化菌需要 CO2、H2、通常还需要 O2、可同化氮和多种营养元素，以及培养、传质、散热和食品加工系统。特定微生物产品已有地球监管记录，但不能扩展为所有菌株、任意培养工艺或火星本地原料都获准食用。[03：C01-05、C01-14、C01-18]

需要分清：

- 氢氧化菌、甲醇营养菌、食用真菌和光合藻类，不是相同工艺；
- 菌体干重不等于可消化蛋白质；
- 某些真菌需要预先生产糖，不能把它们当作直接 CO2 食品路线；
- 地球商业设施的设计产能和企业公告，不等于独立审计的火星生产能力。[03：C01-04–06、C01-15–16]

### 2.6 电力、散热和可靠性应与水同等优先

人工照明、提水、电解、气体压缩、培养、冷凝除湿和食品加工，都需要能源。产能表若只统计种植架或反应器、不统计发电与储能，会导致错误比较。[02：A12；03：C01-04]

低温环境也不代表可以免费散热；低压外界、舱内湿热和不同单元温度需求必须通过具体热管理设备连接。不能把作物停止蒸腾、产氧或结实时的故障视为只有“少收一点菜”。[02：A08–A09；03：第九节]

## 3. 建议的基线系统

以下是依据上述证据提出的工程组织建议，**不是已完成任务论证的配置**。

```text
地球补给：种子、合格营养盐、油脂/维生素、储备食品、催化剂与维修件
                                      │
火星冰/含水原料 → 提取 → 净化与质量检测 → 合格水库存
                                      ├→ 人员与生活用水
                                      ├→ 农业营养液与受控根区
                                      └→ 电解/制造过程用水
火星大气 → 除尘/采集/分离/压缩 → CO2、N2 等原料库存
                                      ├→ 农业气氛调节
                                      └→ 独立验证的制造反应器

作物 + 经验证的微生物/人工食材 + 储备食物 + 强化/补充渠道
                                      ↓
                          加工 → 批次验收 → 储藏 → 菜单 → 人员
                                      ↑                       │
                              合格回收水与养分 ← 分流处理 ← 废物流

电力、储能、温控、散热、自动化、检测和维修支撑所有单元。
未通过质量验收的回收物不直接回到饮水、根区或食品中。
```

初期采用物理化学生命支持与生物模块并存的混合系统，更容易明确故障边界。植物贡献应按实际生长状态计量，而不是把“种植面积足够”当作持续供氧保证。[02：A03、A08–A09；01：R15]

## 4. 分阶段研究与技术路线

阶段按证据和运行能力划分，**不承诺在哪一年完成**。

| 阶段 | 食物策略 | 主要任务 | 进入下一阶段前的证据 |
|---|---|---|---|
| 无人先遣 | 不承担人员口粮 | 水源勘查、原料分析、采水与能源长期运行、原料净化试验 | 经季节变化验证的产水、电力和质量数据 |
| 初期有人驻留 | 储备食品为保障，小型农业补充鲜食 | 环境控制、作物批次、操作工时、卫生与营养监测 | 多轮稳定收获及可恢复的故障记录 |
| 扩展驻留 | 增加主粮、豆类、油料；保留补给与备份 | 完整菜单优化、营养盐回收、食品加工储藏 | 营养完整性、可承受维护负担及库存应急能力 |
| 制造系统集成 | 审慎加入微生物蛋白；研究合成淀粉 | 实际全厂物料/能量账、食品级净化、长期运行 | 不是仅有实验速率，而是合格食品产量与可靠性 |
| 高自给殖民 | 多路径食物与原料生产 | 耗材、种源、设备再制造、人口和供应链变化 | 长期系统闭环及失效恢复证据；本轮尚不能证明已具备 |

“高自给”应分别报告能量、各营养素、水、氧、N/P/K 和耗材的外部依赖，不能压缩为一个没有分母的百分比。

## 5. 证据怎样使用

### 两个维度必须分别保存

1. **证据性质：** 火星当地测量、轨道推断、地球实验、近地空间实验、模型、综述、监管记录、企业自述、设计假设。
2. **实际阅读层级：** 原始全文相关章节、摘要、官方说明、数据元信息、尚未取得。

读到全文不代表技术已经成熟；只读到摘要也不代表其结论没有价值，但不能补写不可见的实验条件。各专题的 E1/E2 等编号只在该专题内解释，**不得跨文档当作统一 TRL 或置信度排名**。全库统一建模字段见 [04](04-simulation-model-and-roadmap.md)。

### 数据进入模型的最低要求

每个数字必须携带：单位、物质基准、适用人群或品种、实验环境、时间口径、系统边界、出处定位、阅读层级和不确定性。未知量保持未知，不自动填成 0、100% 或某个地球平均值。

特别警惕：

- 地球日与 sol，地球年与火星年；
- 鲜重、干重、可食部分、最终摄入量；
- 种植面积、房间占地、光伏用地；
- 工艺循环水、净补水和设备库存；
- 全流程电耗与单一反应的效率；
- 浓度、总资源量和单位时间产能；
- 计划产能、企业宣称、独立运行数据；
- 元素总量、溶解量、植物可用量和人体可利用量。

## 7. 本轮边界和下一轮优先事项

已完成的是可追溯的专题资料整理，而非穷尽性系统综述或最终工程定型。虽然已纳入部分 2025–2026 年来源，**不声称覆盖截至整理日的全部最新进展**。

优先补足：

1. **数据落地：** 下载并冻结 SWIM/MOLA/气候版本，核验空间参考与分辨率，建立候选格点；本轮尚未读取实际地图像元。
2. **作物配方库：** 获取小麦、马铃薯、豆类、油料的原始产量及光照数据，并建立一致质量基准；不把鲜菜产率外推为粮食产率。
3. **食品成分库：** 将实际品种和加工形式与完整氨基酸、脂肪酸、维生素及矿物质数据匹配；目前营养表不是完整数据库。
4. **原料与水试验：** 测含盐原料净水成本、营养盐回收和食品级处理，不使用理论100%回收。
5. **制造原始资料：** 合法取得 ASAP 全文/SI、连续运行和酶寿命数据；若未公开，保留未知，不以媒体数字替代。
6. **系统验证：** 做同一任务条件下的农业/微生物/混合路线比较，纳入季节、故障、工时、备用食品和维修件。

复现检索的问题清单、模型字段和验收案例见 [04](04-simulation-model-and-roadmap.md)。
