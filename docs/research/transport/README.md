## 2. 先给结论：交通应该怎样解决

以下是依据已有资料提出的**工程建议**，不是已经建成的火星交通网络。

### 早期：车辆优先，尽量减少必须运输的距离

- 把井场、加工设备、基地和着陆区的位置作为联合设计问题。水冰多但路线不可达，不一定是更好的基地选择。
- 以电驱地面车辆承担基地搬运和重复货运；早期不假定已有道路网络，也不默认普通汽车在火星可直接使用。
- 常规线路先侦察，建立局部地图与风险标记；空中侦察有助于找路，但不能据Ingenuity成绩推导吨级航空货运。
- 人员远行需要加压、生命支持、通信和救援能力，不能把无人货车参数复制为载人车参数。

证据入口：T03–T09、T12–T15、T17–T18。

### 扩展基地：围绕固定货流建设基础设施

- 高频矿区—基地线路可逐步研究清障、稳定路面、充电点、维修和备份车辆。
- 比较“运低品位原料”与“矿区先提水、只运水或产品”，把当地加工所需电力、维护和处理残渣一起算入。
- 水管/气管适合研究稳定连续流量，但需要保温、泵送、检漏、检修及故障期间库存。
- 铁路或索道只能作为高重复流量下的候选方案；必须先算建设材料、施工能力、维护和替代线路，不能宣称它们已经通过火星验证。

依据与模型边界：完整研究第十节；资源证据见T17及[food资源专题](../food/01-mars-resources-and-sites.md)。道路、铁路和管线比较属于工程推导，不是现成火星运营数据。

### 长期：运输网络而非单台“超级火星车”

远期可比较多个基地、矿山、发电设施和着陆场之间的网络。网络应有绕行、库存缓冲、救援和维修节点。单车速度最高不等于全系统吞吐量最大；装卸口、充电位、加工设备和人力都可能限制运输。

## 3. 哪些说法有依据，哪些仍需验证

| 说法 | 证据判断 |
|---|---|
| 火星轮式车辆能够长期工作 | 有机器人任务实证，但任务速度、质量、载荷和运行方式有严格边界：T02–T09、T21 |
| 无人驾驶可以减少实时地球指令依赖 | 有自主导航经验；不等于任何地形都可无人值守通过：T05、T07 |
| 火星较低重力让所有运输耗能都降为地球约38% | 不成立；惯性不变，牵引与土体行为也变化：T22–T23及第四节物理解释 |
| 直升机能飞，所以可以直接发展吨级空运 | 前半句有实证，后半句没有本轮证据支持：T12–T14、T24 |
| 火星车能像地球燃油车一样吸气燃烧 | 不能直接照搬；大气不是可用的富氧空气，燃烧路线需氧化剂供应：T01、T19 |
| 有核电就等于车辆无限续航 | 不成立；基地供电、车载电源、电池、充电和热控是不同模块：T02、T04、T20–T21 |
| 已有可实测支持的载人加压火星车网络 | 没有；DRA 5.0为参考体系，不是火星运行记录：T15 |
| 矿山产水量等于基地收到的水量 | 不成立；还受装载、运输、损耗、在途库存和接收端限制：第十五节 |

## 4. 最容易误用的数字

- **Perseverance的1,025 kg是整车质量，不是载货量。**[T04]
- **152 m/h是硬平地条件下的最高速度说明，不是全天平均货运速度。**[T04]
- **45°倾斜稳定性不等于能爬45°坡。** 操作限制、地形和轮土作用还需另判。[T04、T23]
- **MMRTG发射时约110 W是稳态电源口径，不是驱动瞬时峰值。** 电池支持更高峰值，且电源随时间衰减。[T02、T04、T21]
- **Ingenuity的72次飞行是小型技术验证与任务经验，不是工业运输产能。**[T12、T24]
- 完整研究第十一节约**17.06 t/sol**的车队吞吐量来自**明确假设的算例**，不是NASA设备指标或可直接采用的火星预测。

## 5. 与food专题如何连接

交通不只是独立的车辆玩法，而是食物系统的前置约束：

```text
水矿/原料矿 → 现场处理与装载 → 在途运输 → 基地接收/验收 → 净化/仓储
                                                                  ↓
                                                          农业与食品制造

每个节点分别记录库存、容量、质量、能源、停机和维修。
```

建议接口：

| food侧已有信息 | transport侧需要补充 |
|---|---|
| 水冰候选区域与资源证据 | 实际可达路线、坡度、表面风险、运输距离 |
| 矿山每日产水 | 装卸容量、车队可用率、管线容量、到货时间 |
| 基地净补水需求 | 连续缺货可承受时间、救援运输和备用库存 |
| 农业/制造用电需求 | 充电和供水运输的额外电力、峰值与季节约束 |
| 食品/试剂/维生素补给 | 着陆场卸货、接驳、储藏条件和到期管理 |
| 原料污染与净化要求 | 运输容器隔离、泄漏、交叉污染和批次追踪 |

本轮没有下载路线地图或计算真实候选基地的通行性，也没有运行车队仿真。food与transport中出现的代表性大气或重力数值，应按各自来源口径保存；正式联模时统一场址、版本、单位和时间步，不将不同摘要表直接拼成同一环境数据集。

## 6. 下一轮优先研究

1. **锁定任务和货流。** 先确定人员、矿区距离、运输介质、需求时序和备用期，再选车辆或管线。
2. **建立可达性地图。** 以SWIM筛资源，以DEM和高分辨率影像筛路线；用近场侦察校验障碍，避免把粗地图像元当安全路面。
3. **补载重车辆证据。** 现有探测车不是货车，需轮土试验、牵引/制动、轮寿命、低温电池和载荷约束数据。
4. **建立离散物流模型。** 显式计算空返、满载、装卸、排队、充电、停车热控、故障和在途库存。
5. **补载人安全约束。** 研究生命支持、自救/互救、医疗、失联安全行为和返回可达性；不先给任意“最大探索半径”。
6. **按流量比较基础设施。** 用同一任务边界比较车辆、管线和固定路面；铁路、索道保持研究候选，不人为指定建设阈值。

本轮资料已提供问题框架和可复算算例，但尚不足以给出真实运输价格、车辆最优规格或最终路网。
