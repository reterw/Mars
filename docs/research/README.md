# 火星殖民仿真研究资料

研究资料按主题归档。每个主题区分实际观测、工程示范、模型估计与设计假设。

## 食物与生命支持

[进入 food 研究资料库](food/README.md)

包括水冰与资源选址、农业、人体营养、循环生命支持、二氧化碳制淀粉、微生物食品、仿真参数和56条来源记录。

## 交通与运输

[进入 transport 研究资料库](transport/README.md)

包括轮式运输、载人加压车与救援、航空侦察、动力与热控、道路/铁路/管线的适用条件、矿区物流、着陆卸货、GIS路径、车队算例和24条来源记录。尚未进行真实场址路网或车辆设计验证。

## 资料使用原则

- 定量参数应连同单位、实验条件、系统边界和出处使用。
- 地面或近地空间实验不自动代表火星运行能力。
- 未知量与设计假设应显式保留，不作为实测结论。
