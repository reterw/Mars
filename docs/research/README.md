# 火星生产底表 v0.1

先读“火星生产仿真_资源产业链与矩阵说明.md”和工作簿的“说明/未闭合项”。

内容：67条资源/指标记录；21种有效主原料当量；41个终端产品；69个选定配方；3个完整产业链森林。

## 使用
1. Excel 的“主原料_毛投入”横轴为终端，纵轴为原料。直接配方D/E列、原料假设E/F列、需求试算D列为编辑入口。
2. HTML提供可展开的全部41棵树。@ID是共享节点引用，不重复建物质节点。
3. JSON和CSV供仿真程序读取；多产品联产请使用process_ledger.csv，不能把粗矩阵简单相加后重复制备副产物。
4. build_model.py、build_reports.py仅依赖Python标准库。运行 python build_model.py 再运行 python build_reports.py 可重建JSON、CSV与Markdown/HTML。它们不会自动重新生成Excel；修改Excel也不会同步静态JSON/CSV。

## 严格边界
这是主量物料/假设BOM原型，不是已闭合的全自产工程体系。未知矿藏没有可采储量；种源是外部初始生物资本；部分电子/精密/化学辅材明确保留外部接口。
T是有限反应的计量，H是设计假设，U是未证实矿藏门槛。作物数据不能直接用作真实水培配方，设备名义标签不保证性能。
