# 能源产业链森林

> 根是终端产品；原料以有效组分当量计。每棵树每种物质仅定义一次；↪ @ID是共享依赖引用，不另建物质节点。完整关系为有向无环投入图，不是不存在共享边的严格数学树。外部成套件不是火星自然资源；本版对这些分支诚实保留边界。

## E01 晶硅太阳能板

单位：**m²组件**。系数等级：**H**。规格：双玻总厚4mm；硅180µm覆盖90%；组件效率假设18%；不含支架/逆变系统。

│  │     └─ ↪ @R02（共享输入引用）
│  ├─ M_AL 金属铝 [中间品]

│  │  └─ ↪ @M_C（共享输入引用）
│  ├─ R18 硼矿B₂O₃当量 [原料]

说明：高级/条件性本地制造；真实电池制程辅料与合格率尚未闭合。启动阶段可进口电池片而本地封装，但该替代路线未混入本矩阵。
